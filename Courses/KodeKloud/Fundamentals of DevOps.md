## Course recap
### 1. Why DevOps? — IT challenges and the evolution of DevOps
- Dev wanted to ship changes fast; Ops wanted stability → "wall of confusion" between them.
- DevOps grew out of this conflict (term popular since ~2009).
- 

### 2. Definition, antipatterns, frameworks
- DevOps = culture + practices that let teams deliver software **fast and reliably** together.
- Antipatterns (what DevOps is NOT): a job title only, a separate "DevOps team" silo, just buying tools.
- Related frameworks: Agile, LEAN, ITIL.
- 

### 3. Culture and shared values
- Culture comes first; tools come later.
- Shared responsibility: "you build it, you run it".
- Blameless culture: learn from failures, don't blame people.
- 

### 4. Cross-functional teams
- One team has all the skills (dev, ops, test, security) to deliver end-to-end.
- Fewer hand-offs → faster and fewer mistakes.
- 

### 5. Incident management (the Ops scenario)
- Clear process for incidents: detect → respond → recover → post-mortem.
- 

### 6. Automation and maturity
- Automate repetitive work: build, test, deploy, infrastructure → [[CI-CD]], [[Terraform]], [[Ansible]].
- Assess how mature the organization's automation is, then improve step by step.
- 

### 7. LEAN
- Eliminate waste, deliver value to the customer, improve continuously.
- Small batches + fast customer feedback.
- 

### 8. Collaboration, sharing, security
- Share information openly between teams.
- Security is built in from the start, not added at the end (DevSecOps).
- 

### 9. Measurement — the four DORA metrics
| Metric | Question it answers |
|---|---|
| Deployment frequency | How often do we deploy? |
| Lead time for changes | Code commit → running in production: how long? |
| Change failure rate | What % of deployments cause problems? |
| Time to restore (MTTR) | How fast do we recover from a failure? |

- Use data to drive improvement (the data scientist scenario).

### 10. Technology choices
- Traditional methods vs CI/CD and platform engineering.
- Choose technology that fits the team, not the hype.

# About this repo (for Claude)

Tuğçe's DevOps learning notes — an **Obsidian vault** synced with the Obsidian Git plugin. She is following KodeKloud courses.

## Rules
- **Notes are written in English**, simple and student-level. Short Turkish explanations are allowed inside a note as `> 🇹🇷 ...` when a concept needs it.
- **Talk to Tuğçe in Turkish** in chat.
- Links between notes use Obsidian wikilinks: `[[Note Name]]`.
- Every note starts with YAML frontmatter including `tags`.
- Follow the templates in `Templates/` when creating notes.
- Folders: `Topics/` (concepts), `Courses/KodeKloud/` (one note per course), `Commands/` (cheat sheets), `Labs/` (lab solutions and errors).
- When adding a new topic note, add it to `00-Home.md` and to the "Related" section of related notes.
- Never delete content Tuğçe wrote; edit and extend it.
- Before editing, `git pull` first. Avoid editing a file she may have unsynced changes in.
- When done, commit and push to `main` (she pulls with Obsidian Git).

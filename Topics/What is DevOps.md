# What is DevOps

## What is it? (one sentence)
A culture and set of practices where development (Dev) and operations (Ops) work together to deliver software **fast and reliably**.

## CALMS — the five pillars
| Letter | Pillar | Meaning |
|---|---|---|
| **C** | Culture | Shared responsibility, collaboration, no blame |
| **A** | Automation | Automate builds, tests, deployments, infrastructure |
| **L** | Lean | Remove waste, small batches, continuous improvement |
| **M** | Measurement | Measure everything, decide with data (DORA metrics) |
| **S** | Sharing | Share knowledge, tools and lessons between teams |

## DORA metrics
1. Deployment frequency
2. Lead time for changes
3. Change failure rate
4. Time to restore service (MTTR)

## Antipatterns (what DevOps is NOT)
- Just a job title
- A separate "DevOps team" that becomes a new silo
- Just buying tools

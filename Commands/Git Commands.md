# Git Commands

| Command | What it does |
|---|---|
| `git clone <url>` | Download a repo to your computer |
| `git status` | What changed? |
| `git add .` | Stage changes |
| `git commit -m "message"` | Save a snapshot |
| `git push` | Send commits to GitHub |
| `git pull` | Get new commits from GitHub |
| `git log --oneline` | Short history |
| `git branch` / `git switch -c new` | List branches / create a new one |
| `git config --global user.name "Name"` | Set your identity (done once) |

> 💡 This vault is itself a Git repo — the Obsidian Git plugin runs these commands for you in the background.

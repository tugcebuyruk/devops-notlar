# Linux

## Nedir?
Sunucuların büyük çoğunluğunda çalışan açık kaynak işletim sistemi. DevOps'ta neredeyse her araç Linux üzerinde çalışır.

## Öğrenilecekler
- [ ] Dosya sistemi yapısı (`/etc`, `/var`, `/home`...)
- [ ] Kullanıcılar, gruplar, izinler
- [ ] Paket yönetimi (`apt`, `yum`/`dnf`)
- [ ] Süreçler ve servisler (`systemd`)
- [ ] Bash script temelleri
- [ ] SSH ile uzak sunucuya bağlanma

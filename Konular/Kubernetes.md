# Kubernetes

## Nedir?
Çok sayıda container'ı birden fazla sunucu üzerinde çalıştıran, ölçekleyen ve ayakta tutan orkestrasyon sistemi (kısaca k8s).

## Öğrenilecekler
- [ ] Mimari: control plane, node, kubelet
- [ ] Pod, ReplicaSet, Deployment
- [ ] Service (ClusterIP, NodePort, LoadBalancer), Ingress
- [ ] ConfigMap, Secret
- [ ] Volume, PersistentVolume
- [ ] Namespace, RBAC
- [ ] `kubectl` kullanımı

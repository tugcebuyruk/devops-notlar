# Terraform

## Nedir?
Sunucu, ağ, veritabanı gibi altyapıyı kod (HCL) ile tanımlayıp oluşturan **Infrastructure as Code** aracı.

## Öğrenilecekler
- [ ] Provider, resource, variable, output
- [ ] `init` → `plan` → `apply` → `destroy` akışı
- [ ] State dosyası ve remote state
- [ ] Module'ler

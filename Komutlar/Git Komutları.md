# Git Komutları

| Komut | Ne yapar |
|---|---|
| `git clone <url>` | Depoyu bilgisayara indirir |
| `git status` | Neler değişti? |
| `git add .` | Değişiklikleri hazırlar |
| `git commit -m "mesaj"` | Kaydeder |
| `git push` | GitHub'a gönderir |
| `git pull` | GitHub'dan çeker |
| `git log --oneline` | Geçmişi kısa gösterir |
| `git branch` / `git switch -c yeni` | Dal listesi / yeni dal |

> 💡 Bu kasanın kendisi bir Git deposu — Obsidian Git eklentisi arka planda bu komutları senin için çalıştırıyor.
